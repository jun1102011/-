# 信号与文件索引

所有CSV第一列为时间s；下列索引从信号第一项计数，不含时间列。原始CSV没有滤波。控制日志0.01 s，CarSim原始输出及执行输入0.0005 s。`raw.mat`为Simulink输出对象，读取CSV前已核对首/末维时间轴，不能随意reshape混排。

|日志|信号顺序|
|---|---|
|repair_entry_diag|1阶段；2进度；3接管权重；4是否在接管范围；5准备失败；6准备计时；7接管计时；8饱和计时；9:15实际七状态；16:22参考七状态；23:25工作点虚拟输入；26:28原反馈请求；29:31限幅限速后虚拟输入；32:35候选轮速；36:39约束轮速；40:43实际轮速；44:47反馈力矩；48:51惯量力矩；52:55实际Fx负载及偏置补偿；56:59限幅前力矩；60:63最终力矩；64虚拟输入约束标志；65轮速投影标志；66最终保护；67:70接地点纵向速度|
|repair_actual_load_allocation|1:4实际Fz；5:8权重；9:10旧支路目标轴Fx；11:14分配轮Fx；15:18实际Fx；19:20未实现轴需求；21:24失载标志；25:26诊断pf/pr；27比例有效；28不等纵向力附加Mz（此项未按前轮转角旋转）|
|repair_entry_force_diag|1:4原逆解诊断轴力Fxf/Fyf/Fxr/Fyr；5:7代数回代残差；8:11实际同序轴力；12:14实际轮胎平面Fx/Fy/Mz；15:17原请求平面合力矩；18:20实际减请求|
|repair_actuator_command|左右前轮角deg、左右前轮角速度deg/s、四轮力矩Nm；这是实际送入CarSim的8路指令|
|repair_plant_raw / sampled|原50路CarSim输出，raw0.0005s / sampled0.01s；需按现有模型的单位换算读取|

七状态为 `[V(m/s),β(rad),AVz(rad/s),κf,κr,Roll(rad),AVx(rad/s)]`；三虚拟输入为 `[前轮角rad,κf_d,κr_d]`；四轮顺序始终FL/FR/RL/RR。局部轮速/转向执行约束及接管阈值集中保存在工作点库，日常入口读取为entry_cfg。

## 证据目录

- `source`：本轮修改前原件、哈希、终点配平及冻结终点控制器。
- `candidate`：已写回的核心模型、入口及配套参数库。
- `results/deployment.json`：写回前后哈希；`final_audit.json`：发布后配置未变核对。
- `results/regression_*`：30 s局部维持及两项扰动回归。
- `results/capture_L0_*` 与 `capture_index.json`：七状态正负扰动及完整接管阈值。
- `results/ordinary_consistent`、`transition_consistent_aux`、`preload_trims`：实际接受工作点与辅助状态一致化。
- `results/point_identification`：局部辨识数据与反馈矩阵；`point_hold_*`：释放验证。原失败试验保留，不覆盖。
- `results/input_branch_refinement`：寻找普通至漂移输入分支的探索记录，不全部用于插值。
- `results/entry_25m`、`entry_50m`：原生对照；summary的事件逻辑时钟比原始相位采样约超前一个控制步长，精确事件时间以raw/phases为准。
- `results/simulink_entry25`、`simulink_formal25`：候选与正式模型25m复测。以正式目录结果为交付依据。
- `results/simulink_interface`：转向短测；早期0.1°门槛未通过，原判定保留。
- `results/simulink_normal`：普通模式回归，新增入漂诊断全零。
- `internal`：构建/求解/验证/汇总脚本，禁止与实际仿真同时启动另一CarSim进程。构建脚本有前置依赖，日常运行不需要调用；`build_actual_loads`会从快照重建候选，不能把它当日常入口。
- `图表`：未滤波数据图，只截取部分时间窗便于看入漂，验收使用完整原始数据。
