# 实际轮荷分配与可选直行入漂模式

正式日常文件仍为 `stabilizer_bar_repair.slx` 和 `a001_new_Design_LQR_Controller.m`。本次增加的 `repair_support/repair_entry_bank.json` 是当前CarSim车辆的工作点与局部反馈参数，不能删除。

## 运行25 m入漂（已在正式目录完成30 s复测）

在MATLAB命令窗口执行：

```matlab
cd('C:\Users\Public\Documents\CarSim2020.0_Data\Extensions\Simulink\00carsim_workspace\009\stabilizer_bar')
repair_run_mode = 'drift_entry';
repair_entry_length = 25;
a001_new_Design_LQR_Controller
open_system('stabilizer_bar_repair')
out = sim('stabilizer_bar_repair');  % 这一行才真正启动30 s仿真
```

从GUI的30 km/h普通初态出发，先加速，再建立滑移/侧偏/横摆，达到条件后切入局部维持。不要恢复漂移初态，不必改CarSim。目标为12 m/s、β−10°、AVz0.6 rad/s；本模式关闭路径LQR及式4.10路径项，不包含退出。

`repair_entry_length=50`已有原生对照通过，本轮未另做50 m全程Simulink复测；25 m是本次正式复测选择。

## 返回原普通路径模式

```matlab
repair_run_mode = 'normal';
a001_new_Design_LQR_Controller
out = sim('stabilizer_bar_repair');
```

新MATLAB工作区默认normal；同一工作区会保留上次显式选择，模型初始化回调会重新执行a001，请留意命令窗口“有效运行模式”。初始化脚本不自动启动仿真。

## 在模型中查看

- `EntryLocalMode`：直行准备、过渡工作点反馈、接管和局部维持。核心公式、状态机及公共轮速历史在块内。
- 原执行器轮速执行块：四轮实际Fz分配，已去掉固定0.7/0.3。局部模式另用实际Fx补偿，不把旧轴力支路并行叠加到轮矩。
- `repair_entry_diag`：阶段0普通、1过渡、2接管、3维持；状态、参考、滑移、轮速和力矩分项。
- `repair_actual_load_allocation`：原轴力分配支路的实测轮荷、权重、目标/实际力与失载诊断。
- `repair_entry_force_diag`：原逆解回代与实际轮胎平面合力残差，属于对照诊断，不驱动车辆。
